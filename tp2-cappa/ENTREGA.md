# Checklist de entrega

## Requisitos de la consigna

- [x] Problema y alcance documentados.
- [x] Datos y procedencia explicados.
- [x] Flujo desde lectura a análisis y salida.
- [x] Funciones, clases y validaciones implementadas.
- [x] Pruebas ejecutables verificadas.
- [x] Repositorio Git ordenado y con historial real.
- [x] Documentación y uso del proyecto.

## Evidencia

- `README.md` del proyecto explica el problema y el uso.
- `src/` incluye la lógica de validación y análisis.
- `tests/` ejecuta verificaciones automáticas.
- `VALIDACION.md` documenta la ejecución real.
